# GeoSentinel Satellite Data

This directory stores satellite datasets for the GeoSentinel pipeline.

## Expected Files (Milestone 2)

We will eventually place the following REAL satellite datasets in the `raw/` subdirectory:

- `sentinel2_t1_b4.tif` - Sentinel-2 Baseline (T1) Red band (B4)
- `sentinel2_t1_b8.tif` - Sentinel-2 Baseline (T1) NIR band (B8)
- `sentinel2_t2_b4.tif` - Sentinel-2 Current (T2) Red band (B4)
- `sentinel2_t2_b8.tif` - Sentinel-2 Current (T2) NIR band (B8)
- `landsat_t2_lst.tif` - Landsat 8/9 Current (T2) Thermal/LST

## Data Integrity Notice
**IMPORTANT**: These must be REAL satellite datasets for the Chennampatti Quarry Cluster study area. Under no circumstances should fabricated, generated, or fake satellite data be placed here.
